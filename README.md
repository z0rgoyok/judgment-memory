# judgment-memory

Цельная модель «память — исполняемая спецификация — код» для людей и машин: нормативная контентно-адресуемая память
суждений, инвариантов и решений о коде. Обобщает baseline
[slopo](https://github.com/z0rgoyok/slopo) до владельцев доменных вопросов, формальных решений в семантике DMN и
трассировки BPMN → решение → код.

Полное описание: [MODEL.md](./MODEL.md). Кейсы применения: [CASES.md](./CASES.md).

Коротко:

- суждение о коде хранится как запись с ключом из хешей кода и версии вопроса;
- изменение кода инвалидирует запись в момент изменения факта;
- gate исполняет записи и блокирует merge при нарушении;
- у доменного вопроса один владелец в коде, остальные места делегируют ему;
- бизнес-правило записано формально, его примеры служат оракулом и тестами;
- дифф модели превращается в точное задание исполнителю;
- спецификация, трассировка и документы — проекции одной памяти, согласованные хешами.
